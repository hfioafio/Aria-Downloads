Le bon micro.
Sans perdre le début.

Aria respecte votre choix de micro. En Automatique, elle privilégie un micro intégré disponible si le micro système est Bluetooth, pour préserver le son du casque. Si le micro disparaît pendant une dictée, l’enregistrement s’arrête et Aria traite l’audio déjà capturé.

  • L’enregistrement démarre avant le vumètre visuel.
  • Le flux est libéré après la dictée.
  • Le texte reste récupérable si l’app cible refuse l’insertion.

Confidentialité lisible

Pas de petite ligne cachée derrière « IA ».

Le mode choisi indique clairement ce qui reste sur le Mac et ce qui rejoint votre fournisseur cloud.

01Local signifie local

Avec Parakeet, ni l’audio ni la transcription ne quittent votre ordinateur.

02Clé serveur jamais embarquée

Le mode Groq fourni utilise une clé conservée sur le serveur. Vos clés optionnelles restent chiffrées dans le Trousseau macOS.

03Historique réglable

Gardez-le, limitez-le ou désactivez-le selon le niveau de confidentialité recherché.

04Contexte facultatif

La lecture d’écran locale pour les noms propres peut être désactivée à tout moment.

05Comptage anonyme, mesure facultative

Pour compter les Mac équipés, Aria télécharge un fichier vide sur GitHub à l’installation, à chaque nouvelle version et une fois par semaine d’usage ; GitHub n’en publie que le total. Ce comptage se coupe dans Réglages → Données. Les statistiques d’usage détaillées restent désactivées tant que vous ne les acceptez pas : seuls des compteurs et un identifiant aléatoire sont alors partagés, jamais d’audio, de texte, d’e-mail, de nom ou d’identifiant matériel. Le retrait demande l’effacement des agrégats associés. Cette vitrine ne transmet aucune visite ni aucun clic.

Questions fréquentes.

Aria traduit-elle automatiquement l’anglais ?

Non. La transcription conserve la langue parlée. Les transformations comme E-mail ou Points clés ne s’appliquent que lorsque vous les choisissez.

Dans quelles apps Aria fonctionne-t-elle ?

Aria écrit au curseur : elle fonctionne donc dans Mail, Messages, Notes, Slack, Teams, les navigateurs, les éditeurs de code et tout champ de texte macOS standard.

Faut-il une connexion Internet ?

Après téléchargement du modèle local, l’audio et la transcription sont traités sur le Mac. La vérification du quota et de la licence peut nécessiter une connexion. Le mode Automatique utilise le service en ligne fourni par Aria, sans clé à saisir pendant la bêta : l’audio passe par un relais limité vers Groq, sans stockage de l’audio ni du texte par ce relais.

Comment fonctionne la limite gratuite ?

Aria Free comprend 2 000 mots par semaine et se remet à zéro chaque lundi selon l’heure du serveur. Une brève connexion est nécessaire pour vérifier le compteur ; réinstaller l’app ou changer l’horloge du Mac ne recrée pas un nouveau quota.

Le paiement de 5 € est-il un abonnement ?

L’achat Pro n’est pas encore ouvert. L’offre annoncée prévoit un achat unique de 5 € pour trois Mac, sans limite de mots et avec les futures mises à jour incluses. La bêta permet de commencer gratuitement avec 2 000 mots par semaine.

Que se passe-t-il pendant une longue dictée ?

Le délai cloud augmente avec la durée enregistrée. Deux minutes de parole disposent d’un délai bien supérieur à une phrase courte avant que le secours local soit envisagé.

Aria fonctionne-t-elle avec les AirPods ?

Oui. Vous pouvez choisir explicitement le micro du casque. En Automatique, Aria privilégie un micro intégré disponible si le micro système est Bluetooth, pour éviter la bascule du casque en mode téléphonique.

Pourquoi macOS affiche-t-il un avertissement ?

Aria est signée mais pas encore notarisée par Apple. Après une première tentative d’ouverture, utilisez Réglages Système → Confidentialité et sécurité → Ouvrir quand même. La future version Developer ID supprimera cette étape.

Comment les mises à jour fonctionnent-elles ?

Aria vérifie le manifeste public au démarrage puis toutes les six heures. Elle reprend si nécessaire le téléchargement du DMG adapté au Mac, contrôle sa taille, son SHA-256 et son identité Apple, puis met l’application à jour sur place. Si la nouvelle version ne démarre pas correctement, Aria restaure automatiquement la précédente. Une version minimale publiée rend cette mise à jour non reportable, sans jamais bloquer Aria hors ligne.

Comment savez-vous si Aria est utilisée ?

Trois chiffres, tenus séparés. Les téléchargements du fichier « Installer » de ce dépôt comptent les téléchargements depuis le site ; ceux du fichier sans « Installer », identique, comptent les mises à jour automatiques. Pour savoir combien de Mac sont vraiment équipés, Aria télécharge un fichier vide sur GitHub à la première ouverture, à chaque nouvelle version et une fois par semaine d’utilisation : GitHub n’en publie que le total, sans identifiant, texte ni réglage. Ce comptage se coupe dans Réglages → Données. Le partage détaillé de lancements et de dictées reste désactivé tant que vous ne l’activez pas.
