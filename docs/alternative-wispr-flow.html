L'écart de prix, en clair

Wispr Flow Pro, c'est 15 $ par mois, ou 12 $ par mois si vous payez l'année d'avance. Soit 144 $ par an, chaque année. Aria Pro, c'est 5 €, une seule fois, sur trois Mac, mises à jour comprises. Pas de renouvellement, pas de compte par personne, pas d'augmentation qui vous attend au quatorzième mois.

Les deux commencent par offrir la même chose : 2 000 mots par semaine. Si vous dictez de temps en temps, les deux sont gratuits et vous pouvez arrêter votre lecture ici. Si vous dictez toute la journée, l'un des deux vous demande le prix d'un café, une fois.

Hors ligne, ce n'est pas une case à cocher

Wispr Flow compresse votre audio et l'envoie sur ses serveurs, où la transcription a lieu. C'est son fonctionnement sur toutes les plateformes : il n'existe pas de mode local à activer. Coupez le Wi-Fi et l'application n'a plus rien à faire.

Aria embarque NVIDIA Parakeet TDT V3 et le fait tourner sur votre Mac. Avec ce moteur, ni l'audio ni la transcription ne quittent la machine — dans un avion, dans un train, sur un poste d'entreprise verrouillé. Vous pouvez toujours choisir un moteur cloud quand vous voulez le maximum de précision sur un accent difficile ; la différence, c'est que ce choix est le vôtre, moteur par moteur, et que vous pouvez utiliser votre propre clé API pour que le fournisseur vous facture directement.

Ce que « local » veut dire, concrètement. Le fichier du modèle est sur votre disque. Une dictée avec ce moteur ne fait aucune requête réseau. L'historique est une base de données locale. Vos clés API éventuelles sont chiffrées dans le Trousseau macOS, pas sur un serveur.

Elle écrit ce que vous avez dit

Aria est fidèle par défaut. Elle rétablit une majuscule ou un point localement, et elle ne résume, ne reformate et ne traduit que si vous le demandez explicitement. La langue parlée est conservée : vous parlez français, vous obtenez du français ; vous basculez en anglais au milieu d'un message, il reste en anglais. Les transformations — E-mail, Points clés — existent, mais c'est vous qui les activez.

Quand un nom sort systématiquement de travers, corrigez-le une fois. Aria repère les mots que vous avez rectifiés et les ajoute à un dictionnaire personnel, sans pour autant obtenir le droit de réécrire le reste de votre phrase.

Quand Wispr Flow reste le bon choix

Cette page ne vaudrait rien si elle prétendait qu'Aria gagne partout. Prenez Wispr Flow si :

  • Vous n'êtes pas uniquement sur Mac. Wispr Flow existe sur Windows, iOS et Android. Aria est macOS uniquement, sans application téléphone.
  • Il vous faut des documents de conformité. SSO, SOC 2 Type II, HIPAA : Aria n'a rien de tout ça et ne prétendra pas le contraire.
  • Vous voulez une entreprise responsable devant une équipe. Aria est l'application d'un développeur indépendant à 5 €, pas un fournisseur avec un chargé de compte.
  • Vous voulez un installeur entièrement notarisé aujourd'hui. Aria est signée avec une identité stable mais pas encore notarisée par Apple : la première ouverture demande un passage par Réglages Système → Confidentialité et sécurité → Ouvrir quand même.

Changer prend deux minutes

  1. Téléchargez le DMG adapté à votre Mac et glissez Aria dans Applications.
  2. Ouvrez-la une fois ; si macOS bloque, autorisez-la dans Réglages Système → Confidentialité et sécurité.
  3. Accordez Micro et Accessibilité — c'est l'Accessibilité qui permet à Aria d'écrire dans les autres apps.
  4. Choisissez le moteur local si vous voulez zéro réseau, puis tapez deux fois la touche ⌘ droite et parlez.

Les questions qu'on nous pose vraiment

Aria est-elle réellement utilisable sans aucune connexion ?

Oui, pour la dictée avec le moteur local. La seule chose pour laquelle l'offre gratuite a besoin du réseau, c'est la vérification du compteur hebdomadaire. Aria Pro supprime même cette étape.

Les 5 €, est-ce un abonnement déguisé ?

Non. C'est un achat unique donnant accès à Aria Pro à vie sur trois Mac, sans limite de mots, mises à jour futures comprises.

Puis-je quand même utiliser la précision du cloud parfois ?

Oui. Aria accepte OpenAI, Groq, Deepgram, Soniox, ElevenLabs et Mistral avec votre propre clé, et propose un mode Groq sans clé à saisir. Vous choisissez moteur par moteur et vous changez quand vous voulez.

Est-ce que ça marche dans Slack, Notion, VS Code, un navigateur ?

Oui. Aria écrit au curseur : tout champ de texte macOS standard fonctionne — Mail, Messages, Notes, Slack, Teams, navigateurs, éditeurs de code.

Pourquoi macOS affiche-t-il un avertissement à la première ouverture ?

Aria est signée avec une identité stable mais pas encore notarisée par Apple. Essayez de l'ouvrir une fois, puis Réglages Système → Confidentialité et sécurité → Ouvrir quand même. Ne le faites que pour un fichier venu de ce site ou du dépôt GitHub officiel.
