Visites du site et usage réel de l'app

Ces chiffres-là existent déjà, mais ils vivent sur le service d'Aria et pas ici : visites, visiteurs uniques, clics sur les boutons de téléchargement, source de chaque visite (Reddit, Hacker News, presse…), installations, lancements, dictées, et surtout le nombre de Mac réellement vus par le service de quota — le seul chiffre qui dit qu'une personne se sert vraiment d'Aria.

Ils s'ouvrent ici, avec votre jeton d'administration :
aria-dictee-mac.buggbrr.chatgpt.site/admin

Pourquoi ce n'est pas fusionné dans cette page : le service refuse d'être lu depuis une autre adresse et d'être affiché dans un cadre. Corriger ça demande de redéployer le service, ce qui passe par votre compte d'hébergement. Une fois fait, tout tiendra sur une seule page.

À savoir pour lire ces chiffres

Les téléchargements GitHub comptent les robots. Les moteurs de recherche et les scanners de sécurité téléchargent les fichiers. Un chiffre qui monte de un ou deux sans visite correspondante sur le site est probablement une machine.

Télécharger n'est pas utiliser. Beaucoup de gens téléchargent, voient l'avertissement de macOS et referment. L'écart entre les téléchargements ici et les Mac vus par le quota est exactement la mesure de ce déchet.

Les statistiques dans l'app sont désactivées par défaut et le resteront tant que l'utilisateur ne les active pas. Les colonnes « lancements » et « dictées » de la page d'administration ne se rempliront donc que pour les gens qui l'acceptent : ce n'est pas une panne.
