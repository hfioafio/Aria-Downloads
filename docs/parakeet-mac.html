Why Parakeet rather than Whisper

Whisper is the model everyone knows, and Aria can run it too. For live dictation, though, Parakeet has a practical edge: it is fast enough on a Mac's CPU that the sentence is ready roughly when you stop talking, and it handles the short, clipped utterances that dictation is actually made of — a subject line, a Slack reply, one sentence in a form. Whisper's large variants are excellent on long, messy audio, and slower.

Aria's rule of thumb: Parakeet for dictating all day, a Whisper variant or a cloud engine when one specific recording deserves the extra accuracy.

The part that is usually the hard bit

Running a local ASR model is the easy half. The hard half is everything around it, and that is what an app is for:

  • Getting the text into the app you are in. Aria types at the cursor in Mail, Slack, Notes, a browser, an editor, so there is no window to copy out of.
  • Not losing the first or last word. Recording starts before the meter appears on screen, and the tail of the sentence is captured rather than cut at the moment you release the key.
  • Microphone changes. AirPods that disconnect mid-sentence fall back to the built-in mic without interrupting the dictation.
  • Vocabulary. Correct a name once and it is added to a personal dictionary, instead of being wrong forever.
  • Not melting your battery. The engine is released when you stop, rather than sitting resident and warm.

What it costs you in machine terms

487 MB of disk, once. Memory is claimed while transcribing and released afterwards. Everything happens on the CPU, so there is no driver, no GPU requirement and no compatibility matrix — an Intel Mac from before the Apple Silicon transition runs the same model, just more slowly.

Where a cloud engine still wins. A heavy accent, a bad phone recording, background music, or rare proper nouns — a large hosted model is still better at those. Aria lets you switch per engine and use your own API key with OpenAI, Groq, Deepgram, Soniox, ElevenLabs or Mistral, so the local model is a default, not a cage.

Questions

Do I need to install Python, conda or anything else?

No. The runtime is bundled in the app. Install the DMG, download the model from inside Aria, and dictate.

Does it really work with no internet?

Yes, once the 487 MB model is downloaded. Only the free plan's weekly word counter needs a brief connection; Pro removes that.

Which languages does Parakeet TDT V3 cover?

25 European languages, and Aria keeps the language you spoke rather than translating it to English.

Can I use Whisper instead?

Yes. Whisper variants are available locally, and cloud engines are available with your own key.

Does it run on an Intel Mac?

Yes. There is a separate Intel build. It is slower than on Apple Silicon but it works.
