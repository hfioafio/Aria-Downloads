The price gap is the whole story

Wispr Flow Pro is $15 a month, or $12 a month if you pay for the year. That is $144 a year, every year. Aria Pro is €5, once, on up to three Macs, with every future update included. There is no renewal, no seat count, and no price rise waiting for you in month fourteen.

Both apps give away the same amount first: 2,000 words a week. If dictation is an occasional thing for you, both are free and you can stop reading here. If you dictate all day, one of them charges you roughly the price of a coffee, once.

Offline is not a checkbox, it is the architecture

Wispr Flow compresses your audio and sends it to its servers, where the transcription happens. That is how it works on every platform — there is no local mode to switch on. Turn off the Wi-Fi and the app has nothing to do.

Aria ships NVIDIA's Parakeet TDT V3 and runs it on your Mac. With that engine selected, no audio and no transcript leaves the machine — on a plane, on a train, on a locked-down work laptop. You can still choose a cloud engine when you want maximum accuracy on a hard accent; the difference is that it is a choice you make, engine by engine, and you can use your own API key so the provider bills you directly.

What "local" means here, concretely. The model file lives on your disk. Dictation with it makes zero network requests. Your transcript history is a local database. Your optional API keys are encrypted in the macOS Keychain, not on a server.

It writes what you said

Aria's default is fidelity. It will fix a capital letter or a missing full stop locally, and it will not summarise, reformat or translate unless you explicitly ask for it. Spoken language is preserved: speak English, get English; switch to French mid-sentence and it stays French. Cleanup modes — Email, Key points — exist, but you turn them on.

When a name keeps coming out wrong, correct it once. Aria notices the words you fixed and adds them to a personal dictionary, so “Groq” stops turning into “Grok” without giving the app permission to rewrite the rest of your sentence.

Where Wispr Flow is the better choice

This page would be worthless if it pretended Aria wins everything. Pick Wispr Flow if:

  • You are not only on a Mac. Wispr Flow runs on Windows, iOS and Android. Aria is macOS only, and there is no phone app.
  • You need compliance paperwork. SSO, SOC 2 Type II, HIPAA — Aria has none of that, and will not pretend otherwise.
  • You want one company accountable for a team. Aria is a single developer's app with a €5 licence, not a vendor with a customer success manager.
  • You want a fully notarised installer today. Aria is signed with a stable identity but not yet notarised by Apple, so the first launch needs one trip through System Settings → Privacy & Security → Open Anyway.

Switching takes about two minutes

  1. Download the DMG for your Mac and drag Aria into Applications.
  2. Open it once; if macOS blocks it, allow it in System Settings → Privacy & Security.
  3. Grant Microphone and Accessibility — Accessibility is what lets Aria type into other apps.
  4. Pick the local engine if you want zero network, then double-tap the right ⌘ key and talk.

Questions people actually ask

Is Aria really usable with no internet at all?

Yes, for dictation with the local engine. The only thing the free plan needs a connection for is checking the weekly word counter. Aria Pro removes even that.

Is the €5 a subscription in disguise?

No. It is a one-time purchase for lifetime access on three Macs, with unlimited words and all future updates included.

Can I keep using cloud accuracy sometimes?

Yes. Aria supports OpenAI, Groq, Deepgram, Soniox, ElevenLabs and Mistral with your own API key, and there is a bundled Groq mode with no key to enter. You choose per engine, and you can switch at any time.

Does Aria work in Slack, Notion, VS Code, a browser?

Yes. Aria types at the cursor, so any standard macOS text field works — Mail, Messages, Notes, Slack, Teams, browsers, editors.

Why does macOS warn me on first launch?

Aria is signed with a stable identity but not yet notarised by Apple. Try to open it once, then use System Settings → Privacy & Security → Open Anyway. Only do that for a file from this site or the official GitHub repository.
