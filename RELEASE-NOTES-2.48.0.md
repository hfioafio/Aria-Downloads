# Aria 2.48.0 — bêta publique

Cette première bêta publique privilégie la fiabilité et la confidentialité :

- choix guidé entre Groq Whisper v3 Précision et transcription locale au premier démarrage ;
- reprise locale en cas de vraie panne réseau, sans remplacer durablement le modèle choisi ;
- récupération des dictées et des insertions qui n’ont pas abouti ;
- mise à jour vérifiée par architecture, taille et SHA-256 ;
- interface et site adaptés aux apparences claire et sombre ;
- mise en pause et reprise des médias, sans laisser un casque Bluetooth muet après la dictée ;
- versions Apple Silicon et Intel compilées puis réellement lancées avant publication.

Cette bêta n’est pas encore notarisée par Apple. Le README et le site décrivent la procédure
« Ouvrir quand même ». Aucune clé API n’est incluse : chaque personne utilise sa propre clé Groq
ou choisit le mode local.
